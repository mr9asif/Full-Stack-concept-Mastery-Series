### 1. What is TypeScript?

TypeScript is a statically typed programming language developed by Microsoft that is a superset of JavaScript. It adds optional static typing and other developer features to JavaScript, and TypeScript code is transpiled into JavaScript before running.

### 2. Why do we use TypeScript?

JavaScript is a dynamically typed language, which means the type of a variable is determined at runtime. Because of this, type-related mistakes can sometimes cause unexpected errors while the application is running. TypeScript solves this problem by adding static typing on top of JavaScript. Since TypeScript is a superset of JavaScript, we can define types and catch many errors during development before the code runs. This improves developer experience, code readability, maintainability, refactoring, and makes large applications easier and safer to manage.

A more interview-friendly natural version:

We use TypeScript because JavaScript is dynamically typed, so many type-related errors are only discovered at runtime. TypeScript is a superset of JavaScript that adds static typing, allowing us to catch these errors during development. It also provides better IDE support, improves code readability and maintainability, and makes large applications easier and safer to manage

### 3. What Problem Does TypeScript Solved?

TypeScript solves many common problems that we face when working with JavaScript, especially in large applications. Since JavaScript is dynamically typed, it's easy to make incorrect assumptions about the type or structure of data, which can lead to unexpected runtime errors. TypeScript helps us catch many of these mistakes during development by providing static typing. It also makes data structures clearer, improves code maintainability, and provides better tooling and autocomplete support for developers

#### TypeScript is not a replacement runtime for JavaScript. It is a development-time layer on top of JavaScript that adds a type system and is eventually converted into JavaScript.

### 5. Is TypeScript a programming language?

TypeScript is a programming language built on top of JavaScript. It extends JavaScript with a static type system and other language features, while remaining compatible with JavaScript.

### 6. Is TypeScript compiled or interpreted?

TypeScript is compiled, or more precisely transpiled, into JavaScript. The resulting JavaScript is then executed by a JavaScript runtime such as a browser or Node.js.

### 7. What is transpilation?

Transpilation is the process of converting source code from one programming language or version of a language into another language or version while preserving its functionality.

### 9. Can browsers run TypeScript directly?

No. Browsers do not natively execute TypeScript.

## 10. Does TypeScript exist at runtime?

Generally, TypeScript types do not exist at runtime.

## 11. Does TypeScript improve runtime performance?

Short answer

TypeScript itself generally does not directly improve runtime performance because most TypeScript type information is removed during compilation.
