# React Interview Questions

A collection of React interview questions covering **fundamentals, components, JSX, hooks, state management, routing, performance, and advanced React patterns**.

---

# React Fundamentals

### Topic: Components, Hooks & State Management

1. **Q1.** What is React and what problem does it solve?

2. **Q2.** What is JSX and why is it used in React?

3. **Q3.** What is the difference between functional and class components?

4. **Q4.** What is the Virtual DOM and how does React use it?

5. **Q5.** Explain the `useState` hook with an example.

6. **Q6.** What is the `useEffect` hook and what are its use cases?

7. **Q7.** What is the difference between controlled and uncontrolled components?

8. **Q8.** What are props in React and how are they passed?

9. **Q9.** What is prop drilling and how can it be avoided?

10. **Q10.** Explain the `useContext` hook with an example.

11. **Q11.** What is the `useRef` hook and when would you use it?

12. **Q12.** What are React keys and why are they important in lists?

13. **Q13.** What is the difference between state and props?

14. **Q14.** How does conditional rendering work in React?

15. **Q15.** What is `React.memo` and when should you use it?

---

# React Advanced

### Topic: Routing, Performance & Patterns

16. **Q16.** What is the `useReducer` hook and when is it preferred over `useState`?

17. **Q17.** Explain the `useMemo` hook and give a use case.

18. **Q18.** What is the `useCallback` hook and when do you use it?

19. **Q19.** What is React Router and how do you set up client-side routing?

20. **Q20.** What is the difference between `useNavigate` and `Link` in React Router?

21. **Q21.** What are custom hooks in React? Write a simple example.

22. **Q22.** What is lazy loading in React and how is it implemented?

23. **Q23.** What are React Error Boundaries and why are they useful?

24. **Q24.** What is the Context API and when should you use Redux instead?

25. **Q25.** Explain the concept of reconciliation in React.

26. **Q26.** What is the difference between `React.Fragment` and empty tags (`<> </>`)?

27. **Q27.** How do you handle forms in React? Explain with Formik or React Hook Form.

28. **Q28.** What is code splitting in React and how does it improve performance?

29. **Q29.** What are portals in React and when are they useful?

30. **Q30.** Explain the lifecycle of a React functional component with hooks.
