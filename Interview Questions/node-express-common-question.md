# Node.js & Express Interview Questions

A collection of Node.js and Express.js interview questions covering **Node.js fundamentals, event loop, Express, middleware, REST APIs, authentication, security, npm, file handling, and backend development**.

---

# Node.js & Express Fundamentals

### Topic: Server, REST APIs & Middleware

1. **Q1.** What is Node.js and how does it differ from browser JavaScript?

2. **Q2.** What is the Node.js event loop and how does it handle asynchronous operations?

3. **Q3.** What is Express.js and why is it used with Node.js?

4. **Q4.** What is middleware in Express.js? Give three examples.

5. **Q5.** What is the difference between `app.use()` and `app.get()` in Express?

6. **Q6.** How do you handle errors in Express.js?

7. **Q7.** What are environment variables and how do you manage them in Node.js?

8. **Q8.** Explain the difference between CommonJS (`require`) and ES Modules (`import`) in Node.js.

9. **Q9.** What is CORS and how do you enable it in an Express app?

10. **Q10.** What is the purpose of the `package.json` file?

11. **Q11.** What is npm and what is the difference between `dependencies` and `devDependencies`?

12. **Q12.** How do you create a RESTful API with Express? Explain the standard HTTP methods.

13. **Q13.** What is JWT (JSON Web Token) and how is it used for authentication?

14. **Q14.** What is bcrypt and why is it used for password hashing?

15. **Q15.** What is the difference between synchronous and asynchronous file operations in Node.js?

---

# Node.js & Express Advanced

### Topic: APIs, Authentication, Security & Backend Concepts

16. **Q16.** What is the difference between authentication and authorization?

17. **Q17.** How does JWT authentication work from login to accessing a protected route?

18. **Q18.** What is the difference between access tokens and refresh tokens?

19. **Q19.** What is the difference between cookies, localStorage, and sessionStorage for storing authentication data?

20. **Q20.** What is the purpose of `express.json()` in an Express application?

21. **Q21.** What is the difference between route parameters, query parameters, and request body?

22. **Q22.** What are HTTP status codes? Explain commonly used codes such as `200`, `201`, `400`, `401`, `403`, `404`, and `500`.

23. **Q23.** How do you structure a Node.js and Express project for scalability?

24. **Q24.** What is the Controller-Service-Repository pattern?

25. **Q25.** What is API validation and why is it important?

26. **Q26.** How do you secure an Express.js application?

27. **Q27.** What is rate limiting and why is it important for APIs?

28. **Q28.** What is Helmet.js and how does it improve Express application security?

29. **Q29.** What is the difference between `PUT` and `PATCH` HTTP methods?

30. **Q30.** How do you handle file uploads in a Node.js and Express application?
