# JavaScript Interview Questions

A collection of JavaScript interview questions covering **fundamentals, ES6+, arrays, objects, asynchronous JavaScript, scope, functions, and advanced concepts**.

---

# JavaScript Fundamentals I

### Topic: Variables, Data Types, Functions & Scope

1. **Q1.** What is the difference between `var`, `let`, and `const` in JavaScript?

2. **Q2.** Explain the concept of hoisting in JavaScript.

3. **Q3.** What are the primitive data types in JavaScript?

4. **Q4.** What is the difference between `==` and `===` in JavaScript?

5. **Q5.** Explain how closures work in JavaScript with an example.

6. **Q6.** What is the difference between `null` and `undefined`?

7. **Q7.** What are arrow functions and how do they differ from regular functions?

8. **Q8.** What is the scope chain in JavaScript?

9. **Q9.** Explain the concept of the Temporal Dead Zone (TDZ).

10. **Q10.** What is a pure function? Give an example.

11. **Q11.** What is the difference between function declaration and function expression?

12. **Q12.** What are default parameters in JavaScript?

13. **Q13.** What is the `typeof` operator and what are its possible return values?

14. **Q14.** Explain type coercion in JavaScript with examples.

15. **Q15.** What is an Immediately Invoked Function Expression (IIFE)?

---

# JavaScript Fundamentals II

### Topic: Arrays, Objects, ES6+ & Async

16. **Q16.** What is destructuring in JavaScript? Explain with array and object examples.

17. **Q17.** What are the spread and rest operators and how are they used?

18. **Q18.** Explain the difference between `map()`, `filter()`, and `reduce()`.

19. **Q19.** What is the difference between `for...in` and `for...of` loops?

20. **Q20.** What are template literals and tagged templates?

21. **Q21.** What is the event loop in JavaScript?

22. **Q22.** Explain how Promises work in JavaScript.

23. **Q23.** What is `async/await` and how does it improve upon Promises?

24. **Q24.** What is the difference between `call()`, `apply()`, and `bind()`?

25. **Q25.** What is prototypal inheritance in JavaScript?

26. **Q26.** Explain the concept of the `this` keyword in different contexts.

27. **Q27.** What are JavaScript modules (`import`/`export`)?

28. **Q28.** What is the difference between shallow copy and deep copy of objects?

29. **Q29.** What are `WeakMap` and `WeakSet` and when would you use them?

30. **Q30.** Explain the concept of memoization with an example.
