# Full-Stack MERN Interview Questions

A collection of full-stack interview questions covering **MERN architecture, frontend-backend communication, authentication, REST APIs, database integration, security, deployment, performance, and real-world application architecture**.

---

# Full-Stack MERN Fundamentals

### Topic: Frontend, Backend, Database & Application Architecture

1. **Q1.** Explain the full request-response cycle in a MERN application.

2. **Q2.** What is the difference between authentication and authorization?

3. **Q3.** How do you implement protected routes in a MERN application?

4. **Q4.** What is the difference between cookies and `localStorage` for token storage?

5. **Q5.** What is REST and what are the principles of a RESTful API?

6. **Q6.** What is the MVC pattern and how does it apply to a MERN application?

7. **Q7.** What is a `.env` file and why should it never be committed to Git?

8. **Q8.** What is Axios and how does it differ from the Fetch API?

9. **Q9.** How do you handle CRUD operations between a React frontend and Express backend?

10. **Q10.** What is deployment and what platforms can you use to deploy a MERN application?

16. **Q16.** How do you implement role-based access control (RBAC) in a MERN application?

18. **Q18.** How do you handle errors consistently across the frontend and backend?

19. **Q19.** What is API versioning and why is it useful?
